# Verkonhallinta-niko

Tämä repositorio on verkkoinfrastruktuurin suunnittelu- ja hallintaharjoitus. Se sisältää verkon topologian kartoituksen, IP-osoitteiden dokumentoinnin, reitityksen tutkimisen ja viikoittaiset raportit projektin etenemisestä.

## Sisältö

- `reports/` – viikoittaiset raportit ja dokumentaatio
- `README.md` – projektin yleiskuvaus

## Tarkoitus

Harjoitella verkon rakentamista, hallintaa ja monitorointia sekä ymmärtää reitityksen, palvelinverkkojen ja turvallisuuden perusperiaatteet käytännön esimerkkien avulla.
